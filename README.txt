Home Mortgage Calculator Assignment

Files included:
- mortgage.htm
- calculator.js

How it works:
The web page displays a Home Mortgage Calculator inside the page template. The user enters the mortgage amount, interest rate, and number of years, then clicks Calculate. The page connects to calculator.js, which reads the form values and calculates the estimated monthly payment.

Formula note:
The script changes the annual interest rate into a monthly interest rate by dividing by 1200. It changes the years into monthly payments by multiplying the years by 12. Then it uses the mortgage payment formula to calculate the monthly payment.

To post online:
Upload mortgage.htm and calculator.js into the same GitHub repository or server folder. The calculator.js file must stay in the same folder as mortgage.htm so the script link works.
